# ICD-10-PCS Definitions File: Includes

ICD-10-PCS Definitions File: Includes

## Usage

``` r
pcs_includes
```

## Format

### `pcs_includes`

A data frame with 710 rows and 6 columns:

- entry:

  Entry number

- section:

  PCS section character

- axis:

  PCS code position

- name:

  PCS code position name

- term:

  PCS code position term

- includes:

  PCS code includes attribute
