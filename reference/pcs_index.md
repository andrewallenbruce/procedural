# ICD-10-PCS Index File

ICD-10-PCS Index File

## Usage

``` r
pcs_index
```

## Format

### `pcs_index`

A data frame with 65,333 rows and 11 columns:

- record_index:

  description

- entity:

  description

- entity_index:

  description

- field:

  description

- value:

  description

- value_kind:

  description

- source:

  description

- record_node_id:

  description

- entity_node_id:

  description

- parent_entity_node_id:

  description

- source_node_id:

  description
