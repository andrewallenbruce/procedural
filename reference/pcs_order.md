# ICD-10-PCS Order File

ICD-10-PCS Order File

## Usage

``` r
pcs_order
```

## Format

### `pcs_order`

A data frame with 80,174 rows and 5 columns:

- order:

  code order number

- valid:

  code is valid billing code

- code:

  ICD-10-PCS code

- description_short:

  code description, short

- description_long:

  code description, long
