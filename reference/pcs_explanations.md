# ICD-10-PCS Definitions File: Explanations

ICD-10-PCS Definitions File: Explanations

## Usage

``` r
pcs_explanations
```

## Format

### `pcs_explanations`

A data frame with 60 rows and 6 columns:

- entry:

  Entry number

- section:

  PCS section character

- axis:

  PCS code position

- name:

  PCS code position name

- term:

  PCS code position term

- includes:

  PCS code includes attribute
