# PCS Code Order/Range

PCS Code Order/Range

## Usage

``` r
order(x)

range(start, end)
```

## Arguments

- x:

  description

- start, end:

  `<chr>` Full 7-character ICD-10-PCS code.

## Value

a [tibble::tibble](https://tibble.tidyverse.org/reference/tibble.html)
containing the results
