# ICD-10-PCS Definitions

ICD-10-PCS Definitions

## Usage

``` r
definition(section = NULL, axis = NULL, term = NULL)

includes(section = NULL, axis = NULL, term = NULL)

explanation(section = NULL, axis = NULL, term = NULL)
```

## Arguments

- section:

  `<chr>` PCS section; one of `0:9, B, C, F, G, H, X`

  - Operation: `0:9, X`

  - Approach: `0:4, 7:9, X`

  - Type: `B, C, F, G, H`

  - Type Qualifier: `F`

  - Qualifier: `G`

- axis:

  `<int>` PCS axis; one of `3, 4, 5`

  - `3`: Operation (91) \| Type (46)

  - `4`: Qualifier (15)

  - `5`: Approach (39) \| Type Qualifier (129)

- term:

  `<chr>` term to search for

## Value

a [tibble::tibble](https://tibble.tidyverse.org/reference/tibble.html)
containing the results
