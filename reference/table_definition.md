# ICD-10-PCS Definition Tables

ICD-10-PCS Definition Tables

## Usage

``` r
table_definition
```

## Format

### `table_definition`

A data frame with 861 rows and 6 columns:

- entry:

  Entry number

- section:

  PCS section character

- pos:

  PCS code position

- name:

  PCS code position name

- term:

  PCS code position term

- field:

  PCS code attribute category

- value:

  PCS code attribute description
