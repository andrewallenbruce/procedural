# ICD-10-PCS Definitions File

ICD-10-PCS Definitions File

## Usage

``` r
pcs_definitions
```

## Format

### `pcs_definitions`

A data frame with 2,212 rows and 7 columns:

- entry:

  Entry number

- section:

  PCS section character

- axis:

  PCS code position

- name:

  PCS code position name

- term:

  PCS code position term

- field:

  PCS code attribute category

- value:

  PCS code attribute description
