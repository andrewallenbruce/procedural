``` r

```

## Format

### `pcs_definitions`

A data frame with 3,602 rows and 15 columns:

- record_index:

  description

- entity:

  description

- entity_index:

  description

- field:

  description

- value:

  description

- value_kind:

  description

- source:

  description

- record_node_id:

  description

- entity_node_id:

  description

- parent_entity_node_id:

  description

- source_node_id:

  description
